Every repair starts with your review.

The agent tests queries and proposes an exact patch. Changes require approval and pass recovery checks.

From a missing panel to a verified repair

  1. Check. The scheduler inventories dashboards and evaluates each supported query in its configured context.
  2. Investigate. Collect the original response, an actual Grafana screenshot, change context and live candidate tests.
  3. Review. Inspect the query diff. Approve this exact proposal, reject it, or repair the dashboard yourself.
  4. Verify. The agent checks the saved revision and repeats the panel contract against fresh evaluations.
  5. Learn. Save evidence, decisions, recovery results and prevention recommendations in an RCA.

Supported in this release

Standard Grafana dashboards with explicit Prometheus data-source UIDs, ordinary queries and resolved variables. Library panels, transformations, repeated panels, time overrides and other data sources are explicitly unverified.

Diagnosis mode

Only a unique, configured semantic label migration that passes the live contract becomes an executable patch. Other model suggestions remain advisory. Source-sample freshness can be enforced with a raw-selector contract.
