# Security

This project is a prototype. Its production reviewer token is a shared credential, not an enterprise identity system. Bind to loopback or an authenticated TLS reverse proxy and grant Grafana permissions only on the intended resources.

Detection has no automatic write path. A policy-validated proposal and explicit approval are required for a dashboard repair. The optional model has no write tools. Simulated demo controls are restricted to the synthetic configuration.

Evidence can contain telemetry, dashboard context and deployment details. Keep the state directory private and back it up under the same access policy. Enabling the model advisor transmits its configured evidence to that API.

For a sensitive vulnerability, use the repository's private vulnerability reporting if available. Do not put working exploits, credentials or production telemetry in a public issue. Ordinary defects without sensitive details can be reported in an issue.
